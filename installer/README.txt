Wireless Battery Monitor
========================

Shows the battery levels of your wireless mouse, headset, keyboard and controller on the Windows taskbar.

Getting started
---------------
1. After the app starts, device icons and battery percentages appear on the taskbar, left of the clock.
   Click them for the menu; "Show as tray icons" switches to one tray icon per device.
2. The menu lets you show or hide each device, refresh now, start with Windows, change the language and
   choose which monitors show the widget.
3. A red number means 15% or less; a blue lightning bolt means charging; a sleeping device keeps its last level.
4. "One device at a time" in the menu shows a single device; switch with the mouse wheel over the widget.
5. Some headsets need headsetcontrol.exe; keep it in the same folder as WirelessBattery.exe.

Language
--------
The interface follows the Windows display language when a translation exists, otherwise English.
Change it under "Language" in the menu. To add a language, put your own .txt file in
%APPDATA%\WirelessBattery\lang.

Uninstall
---------
Settings > Apps > Installed apps > "Wireless Battery Monitor" > Uninstall, or run Uninstall.exe in the
install folder. This also removes the startup entry and the app's settings.
